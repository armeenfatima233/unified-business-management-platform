# Reference Direction — HubSpot CRM

Reference: https://www.hubspot.com/products/crm

The supplied reference uses a clean, spacious SaaS visual language with warm white/off-white backgrounds, dark navy typography, generous whitespace, rounded but restrained content blocks, clear section hierarchy, simple navigation, and a distinctive orange/coral accent. The page avoids dense admin-dashboard clutter and favors short descriptions, clear primary actions, and focused content sections.

For LeadSafe, this direction is adapted to the authenticated business application rather than copied as a marketing page. The existing Lead Safety Pulse, attention table, Recovery Queue, pipeline, team readiness, appointments, and payments remain the product priorities. The visual refinement uses a warm neutral canvas, deep navy text, a single orange brand accent, softer borders/shadows, and more disciplined color use for urgency states.
